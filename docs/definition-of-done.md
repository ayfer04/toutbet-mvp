# Definition of Done - ToutBet'

Une user story est "Done" si :
- [ ] Ses abuse stories ont un test automatisé qui passe
- [ ] PHPStan (niveau max) sans erreur
- [ ] composer audit et npm audit sans vulnérabilité haute/critique
- [ ] gitleaks : aucun secret détecté
- [ ] En-têtes HSTS et CSP vérifiés
- [ ] Revue de code humaine par le Security Champion
